The render pipeline is a `high-level`, **engine-defined process** that manages how scenes are drawn **overall**.

It controls **when and how** the graphics pipeline is used, including:

- Camera rendering order
- Lighting models
- Shadow passes
- Post-processing
- Sorting objects
- LOD (Level of Detail)

Used in **Game Engines like Unity (URP/HDRP), Unreal Engine, Godot or any custom engine.**

**Define how the entire frame is built, often using multiple draw calls and graphics pipeline invocations.**

*It's actually the script that tells the engine how to draw the whole scene.*
