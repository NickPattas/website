A decision tree is a **decision support recursive partitioning structure** that uses a tree-like model of decisions and their *possible consequences*, including *chance event outcomes*, *resource cost*s, and *utility*. It is one way to display an algorithm that only contains **conditional control statements**.

Decision trees are commonly used in operations research, specifically in *decision analysis*, to help identify a strategy most likely to reach a goal, but are also a popular tool in machine learning.

It is a *non-parametric supervised learning algorithm*, which is utilized for both **classification and regression tasks**. It has a hierarchical, tree structure, which consists of a **root node, branches, internal nodes and leaf nodes**.
