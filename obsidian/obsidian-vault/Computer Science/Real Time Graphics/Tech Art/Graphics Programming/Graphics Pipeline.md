The graphics pipeline is the **low-level, hardware-driven sequence of stages** that the GPU uses to turn 3D data into a 2D image. It’s a **fixed series of programmable and fixed-function stages** like vertex processing, rasterization, and fragment shading.

**Stages Include**:
- Input Assembler
- Vertex Shader
- (Optional) Geometry Shader / Tessellation
- Rasterizer
- Fragment (Pixel) Shader
- Output Merger
