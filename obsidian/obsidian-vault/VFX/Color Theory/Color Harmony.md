**In painting is recommended to start with the neutrals and build towards saturated.**


Is possible to go from warm to cold using **Hue Shift** without change the saturation. Although, this is *not recommended* because it create an **oversaturated** and **"noisy"** image.

As an alternative we could reduce the saturation of every value and increase it in Colors we want to stand out.

## Constrained Hue Range

![[Pasted image 20251107101607.png|500]]
![[Pasted image 20251107101955.png|500]]

**A constraint range of Hues preventing the viewer for being overstimulated.**

![[Pasted image 20251107102451.png]]

We can avoid completely white colors by **bending** the path between warm and cold colors.
By bending the path more we can get more saturated in between colors in case we need it.

In context the less saturated color will appear white (or really light) to the eye.

**A good rule of thump is always avoid completely white.**
